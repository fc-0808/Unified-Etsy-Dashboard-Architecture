1) Add a group scheduler with jitter
Each shop should get:

base scheduled time
fixed per-shop offset
randomized jitter
randomized retry delay
This prevents same-second clustering.

2) Bind every API client to a single shop context
Each shop sync job should carry:

shop ID
group ID
proxy URL
credentials
token state
No shared mutable client across groups.

3) Add a mandatory proxy verification gate
Before any sync:

check outbound IP through the expected proxy
compare against expected proxy identity
abort if mismatch
4) Add “fail closed” network handling
If a proxy disconnects:

stop requests immediately
never downgrade to direct IP
mark the sync as invalid
alert operator
5) Separate OAuth from sync runtime
Keep OAuth browser authorization in AdsPower, but ensure:

the access token is stored per shop
refresh token rotation is handled centrally
token refresh requests also use the correct proxy context if needed
6) Log network identity for audit
Log for each sync:

timestamp
shop ID
group ID
expected proxy
observed egress IP
result of verification
sync start/finish time
